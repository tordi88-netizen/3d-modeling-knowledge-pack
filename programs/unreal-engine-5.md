# Unreal Engine 5 Notes

## Best use cases
- Real-time asset validation
- Material testing
- LOD review
- Nanite-era asset presentation

## Workflow notes
- Validate scale immediately.
- Check shading, roughness, and normal response in-engine.
- Use UE5 as a truth test for real-time presentation.
- Organize import folders and naming consistently.
- Verify collision, pivots, and LOD behavior as part of asset finalization.
