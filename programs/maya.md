# Maya Notes

## Best use cases
- Hard-surface modeling
- Retopology
- UV layout
- Scene assembly
- Rig-adjacent modeling prep

## Workflow notes
- Use blockouts aggressively before detail.
- Keep transforms clean before duplication and instancing.
- Use naming conventions from the start.
- Combine and separate meshes intentionally to keep outliner clarity.
- Use Maya for cleanup even if sculpting starts elsewhere.
