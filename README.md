# 3D Modeling Knowledge Pack

MCP-ready reference pack for 3D modeling workflows, techniques, and program-specific guidance.

## Purpose
This repository is structured so an AI assistant, MCP server, or human can quickly load practical modeling guidance without digging through scattered tutorials.

## Included
- Core modeling principles
- Topology and edge-flow guidance
- Hard-surface workflow notes
- Organic modeling workflow notes
- UV and baking basics
- Program-specific notes for Maya, ZBrush, Substance 3D Painter, Unreal Engine 5, and NukeX
- Prompt/context templates for AI-assisted modeling sessions

## Suggested use
Point an MCP-aware tool or AI assistant at this repo, then reference the relevant markdown files as context before asking for help.
